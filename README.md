# CV-лендинг Екатерины Ибрагимовой

Сайт: https://kateibragimovaspb-svg.github.io

Страница публикуется через GitHub Pages: после каждого сохранения в ветке `main` сайт обновляется за 1–2 минуты.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | вся страница: тексты, стили, скрипты |
| `img/` | фото, скриншоты сайтов, обложки Хабра, логотипы каналов |
| `.nojekyll` | служебный файл: GitHub отдает страницу как есть |

## Как поправить текст прямо на GitHub

1. Откройте `index.html` в репозитории и нажмите карандаш (Edit this file).
2. Найдите нужную фразу через Ctrl+F и поправьте ее.
3. Нажмите **Commit changes** и коротко опишите правку, например «Обновила цифры Хабра».
4. Подождите 1–2 минуты и обновите сайт. Если изменения не видны, нажмите Ctrl+F5.

## Как заменить картинку

1. Откройте папку `img/` → **Add file → Upload files**.
2. Загрузите файл с тем же именем, что у старого. Тогда в `index.html` ничего менять не нужно.

Скриншоты лучше сохранять в JPG шириной около 960 px, тогда страница грузится быстро.

## Где менять цифры Хабра

Статьи Хабра записаны в `index.html` в скрипте: найдите `var habr=[`. У каждой статьи есть номер на Хабре (`id`), заголовок (`t`), строка «о чем» (`d`), охват (`v`), плюсы (`p`) и закладки (`f`).

## Что не загружать

Репозиторий публичный: любой файл отсюда может скачать кто угодно. Не кладите сюда резюме с телефоном, датой рождения или адресом. Для кнопки «Резюме в PDF» нужна отдельная версия без этих данных.
